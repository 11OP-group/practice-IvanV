VS Code

## Версия:

1.137

## Минимальные системные требования:

ОС: Windows 10-11, MacOS (версии для которых выходят обновления безопасности Apple), Linux (официально поддерживаются Ubuntu 20.04, Debian 10, RHEL 8, Fedora 36 и видимо новее, а неофициально все популярные дистрибутивы)

Место на диске: 500 MB
Процессор: 1.6 GHz
Оперативная память: 1 GB
(Но нужно больше, особенно с расширениями. Привет electron, ещё 1 Chromium.)

## Типы лицензий
MIT License (свободная, не вирусная)

## Языки программирования
Python
Golang
Java

## Ключевые расширения

SQLite Viewer – показывает содержимое sqlite файлов
GitLens – улучшеная работа с git. Фич куча, наверное самая узнаваемая это указание у строчек кода коммита в котором они были изменены в последний раз.
Project Manager – удобное переключение между разными проектами.
