# ConsoleBank

Учебная консольная программа на C#: расчёт дохода по банковскому вкладу.

## Запуск

выполните в папке проекта:

```shell
dotnet run
```

Введите сумму вклада больше нуля и срок: 91, 181 или 365 дней.
При ошибке программа предложит повторить ввод.

Годовая ставка зависит от срока: 11,50% для 91 дня, 11,75% для 181 дня
и 12,50% для 365 дней.
Ежедневный доход рассчитывается как сумма вклада × годовая ставка / 100 / 365.
Доход за весь срок равен ежедневному доходу, умноженному на количество дней.
Проценты начисляются без капитализации.

Программа выводит годовую ставку, доход за день, доход за весь срок
и итоговую сумму на счёте. Денежные значения выводятся с двумя знаками после запятой.
