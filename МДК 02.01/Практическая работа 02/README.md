# GladiatorBattle

Учебная консольная программа на C#: бой двух гладиаторов.

## Запуск

выполните в папке проекта:

```shell
dotnet run
```

Введите здоровье и броню каждого бойца. Здоровье должно быть больше нуля,
броня — больше нуля и не больше 100 процентов.

В каждом раунде оба бойца наносят случайные удары от 30 до 75.
Перед расчётом урона броня получателя уменьшается на четверть силы удара
(в процентных пунктах), до минимального значения 0.
Оставшаяся броня уменьшает урон в процентах.
Удары одновременные: бой заканчивается гибелью одного или обоих бойцов.
Программа выводит ход боя, результат и общее количество ударов.
